# AlignUI CLI Usage

This doc explains what to pass to each CLI command, especially `collect`.

## Build (Required Once After Pull)

```powershell
npm -ws run build
```

Run commands via:

```powershell
node packages/cli/dist/index.js <command> [options]
```

## `collect` (Generate `snapshots.json` From A Live Site)

### What It Needs

`collect` needs 2 things:

1) A config file that defines **what to check** (selectors + CSS properties):
- `--config <path>` (default `.alignui.json`)

2) A live URL to open in a browser:
- `--url <https://...>`

### What It Produces

It writes a `snapshots.json` file that contains, for each rule selector:

- `selector` (same selector from your config rule)
- `url` (the URL you passed)
- `computed` (the computed CSS values for the properties referenced in your config rule)
- optional `text` (element text content)

Output path:
- `--out <path>` (default `alignui/snapshots.json`)

### Optional Flags

- `--wait-for <cssSelector>`: wait for a selector before collecting (useful for SPAs)
- `--timeout-ms <ms>`: page/selector timeout (default `30000`)
- `--headed`: run with a visible browser window

### Example (Typical)

```powershell
node packages/cli/dist/index.js collect --config .alignui.json --url https://app.example.com --out alignui/snapshots.json --wait-for "body"
```

### If You Don’t Have `.alignui.json` Yet

Generate starter files:

```powershell
node packages/cli/dist/index.js init --force
```

Then edit `.alignui.json` selectors/properties to match your app.

### Common Mistakes

- If selectors in `.alignui.json` do not exist on the page:
  - `collect` prints `Missing selector: ...`
  - those selectors will not be included in `snapshots.json`
- If the page needs login/state:
  - v1 `collect` will not handle auth flows yet (next feature would be `--storage-state` or `--script`)

### Playwright Browser Install

If Playwright says Chromium is missing:

```powershell
npx playwright install chromium
```

## `scan` (Compare Tokens vs Snapshots)

`scan` needs:

- `--config <path>`: rules (selectors + token mapping)
- `--tokens <tokens.json>`: expected token values (colors, px numbers, box shorthands, etc.)
- `--snapshots <snapshots.json>`: actual computed styles (generated by `collect` or provided manually)

Example:

```powershell
node packages/cli/dist/index.js scan --config .alignui.json --tokens alignui/tokens.json --snapshots alignui/snapshots.json --out report.json
```

Baseline diff (optional):

```powershell
node packages/cli/dist/index.js scan --config .alignui.json --tokens alignui/tokens.json --snapshots alignui/snapshots.json --baseline report.json --diff-out diff.json
```

## `validate` (No Scan, Just Validate Inputs)

Use this when you want to confirm files are correct before scanning:

```powershell
node packages/cli/dist/index.js validate --config .alignui.json --tokens alignui/tokens.json --snapshots alignui/snapshots.json
```

## `init` (Scaffold Starter Files)

```powershell
node packages/cli/dist/index.js init --force
```

Creates:

- `.alignui.json`
- `alignui/tokens.json`
- `alignui/snapshots.json`
