Check live UI against expected design values.

DesignLatch is a CLI-first design compliance tool. It compares expected token values with computed styles from a running site, then generates JSON and HTML reports so teams can review drift with something measurable instead of subjective visual QA.

Quick Start Open Docs

What it does

You define selectors and property expectations in .designlatch.json, provide a manual tokens.json, collect computed styles with Playwright, and run a scan that writes a compliance report.

Install @designlatch/cli
Outputs report.json + html
Collector playwright
Usage npx designlatch

Use the docs for details

The full docs page contains the command guide, install flow, examples, required inputs, and report flow. The landing page stays intentionally minimal.
