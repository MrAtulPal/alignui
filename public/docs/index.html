Setup

Quick start

This is the shortest path to a working AlignUI run after installing the published CLI package.

1

Install

Add the CLI to your project as a dev dependency.

bash
npm install -D @alignui/cli
2

Initialize

Create starter config and template files.

bash
npx alignui init --force
3

Collect

Capture computed styles from the running site.

bash
npx alignui collect --config .alignui.json --url https://app.example.com --out alignui/snapshots.json --wait-for "body"
4

Scan

Compare tokens against snapshots and write the report.

bash
npx alignui scan --config .alignui.json --tokens alignui/tokens.json --snapshots alignui/snapshots.json --report-dir report
Flow

Workflow

AlignUI follows a simple pipeline: define rules, collect actual styles, compare against expected values, then review the report.

01

Define

Map selectors and CSS properties inside .alignui.json.

02

Expected

Provide the design values in alignui/tokens.json.

03

Actual

Generate alignui/snapshots.json from the live site with collect.

04

Report

Run scan and review the generated JSON and HTML results.

Docs

Command guide

Each command below includes what it does, what you need to pass, and one working example.

bootstrap

init

Create starter files for a fresh AlignUI workspace.

Needs: optional --config, optional --force Example: npx alignui init --force
collection

collect

Open the site in Playwright and write computed CSS values to snapshots.json.

Needs: --config, site --url or config.url, --out Example: npx alignui collect --config .alignui.json --url https://app.example.com --out alignui/snapshots.json --wait-for "body"
validation

validate

Validate config, tokens, and snapshots without running the compare engine.

Needs: --config, --tokens, --snapshots Example: npx alignui validate --config .alignui.json --tokens alignui/tokens.json --snapshots alignui/snapshots.json
scan

scan

Compare expected token values with collected snapshots and write reports.

Needs: --config, --tokens, --snapshots, optional --report-dir Example: npx alignui scan --config .alignui.json --tokens alignui/tokens.json --snapshots alignui/snapshots.json --report-dir report
report

serve

Serve an existing report directory or HTML file locally in the browser.

Needs: --report-dir or --file Example: npx alignui serve --report-dir report
help

help

Show the compact terminal help and point users back to the docs page.

Needs: no flags Example: npx alignui help
Reference

Inputs

These are the files AlignUI expects during a normal run.

config

.alignui.json

Defines the page URL, rules, selectors, and which properties map to which tokens.

json
{
  "url": "https://app.example.com",
  "rules": [
    {
      "id": "primary-button",
      "selector": ".btn-primary",
      "properties": {
        "backgroundColor": { "token": "color.primary", "tolerance": { "kind": "rgba", "value": 0 } }
      }
    }
  ]
}
expected

tokens.json

The expected design values that the scan engine compares against.

Passed with --tokens alignui/tokens.json
actual

snapshots.json

The computed style capture created by the collect command.

Passed with --snapshots alignui/snapshots.json
baseline

report.json

Optional previous report used for diff output between two runs.

Use --baseline report.json --diff-out diff.json
Reference

Reports

AlignUI writes both machine-readable and browser-readable output.

json

report/report.json

Contains score, failures, and per-rule result details.

html

report/index.html

Minified HTML report for reviewing the compliance result in a browser.

served

alignui serve

Runs a local HTTP server so the HTML report opens cleanly in a browser.

status

Exit code

The scan exits successfully on pass and non-zero when thresholds are not met.
